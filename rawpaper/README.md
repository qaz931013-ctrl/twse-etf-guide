# 論文與延伸文獻存放區（`rawpaper/`）

本目錄專門存放使用者於對話中提供之 **PDF 論文、學術研究、機構研究報告或額外參考資料**。

## 處理與 Ingest 規範
1. **原始保存**：使用者提供的原始 PDF 或文件原樣存入本目錄，不修改原始內容。
2. **抽取與對照**：
   * 當新資料存入 `rawpaper/` 後，人工智慧應進行內容解析，標記其核心觀點、實證數據或學術結論。
   * 與現有 `wiki/` 頁面進行比對，確認是否補充了新觀點（如不同市場的實證、更深入的費用率模型、折溢價套利極限研究等）。
3. **知識庫整合**：
   * 若獲取使用者同意，將相關摘要寫入 `wiki/` 對應主題頁面，並標註 `[來源：rawpaper/檔案名稱]`。
   * 同步更新 `wiki/index.md` 與 `wiki/log.md` 紀錄。
